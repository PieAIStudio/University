# 主行动按钮：静止态的材质 pass

分支 `work/ctamaterial`。这一轮不加动效，只让**不动的时候**看起来值钱。

## 背景

第一轮把 LiquidGroup 的 waviness 加到了静止态，波浪边缘读作"渲染坏了"而不是"贵"。
根因写进了项目记忆：**gooey 只在形状融合、流动、或响应交互时才好看；
贴在一块静止的实心矩形上就是缺陷。** 第二轮把液体效果移到按下交互，
静止态回到干净的实心。这一轮补的是静止态本身的说服力。

## 这一轮做了什么

材质与光照承担"贵"，几何承担"对"（和 LOOK-V2 §11 对 3D 的那条同源）：

1. **垂直渐变** — 顶亮底暗，底部再压一档向文字色靠。给按钮体积感。
2. **顶边光** — 一条 1.5px 的高光，**两端渐隐**。
3. **接触阴影** — 短而暗，读作"它放在那儿"，不是浮着。
   走 SwimmerUIKit 2.0.0 的 compositor `drop-shadow()` 路径，静止零成本。
   **不许退回昂贵的 SVG filter 路径。**
4. **字重** — 800，`letter-spacing: -0.01em`。

## 主控这一轮亲自改的两处

代理交出的版本我在真实浏览器里放大到 2.6 倍看过，改了两处：

- **删掉重复的光源。** `--liquid-cta-shadow` 里还有一条 `inset 0 2px 0` 的白线，
  和 `::before` 的高光叠在一起，按钮上出现**两条**亮带。
  一个光源是这条设计的全部意义，删掉 inset 那条。
- **高光两端由硬变虚。** 原来是一条 2px 的胶囊，有硬边端点，
  读作"粘在按钮上的一根条"，不是"光落在弧面上"。改成沿长度渐隐。
  这和第一轮 waviness 的错误是同一类：装饰性元素读成了缺陷。
- 顺带把渐变加深了一档，原来的几乎看不出来——看不出来的渐变没有在做它被加进来的那件事。

## 实测

- 文字对比度：顶部 **8.79:1**、底部 **6.62:1**（AA 要求 4.5:1）
- 静止态动效：**无**。没有 ambient 动画，没有 idle 成本。
- 每屏只有 **1 个** liquid CTA（首页实测 `document.querySelectorAll('.liquid-cta').length === 1`）。
  稀缺性是它读作"按这里"而不是装饰的原因。
- 按下：轮廓 0.95 缩放 + 下沉，**DOM 文字不缩放**，点击区域和焦点环不变。
- `prefers-reduced-motion` 和 `disabled` 都走静止分支。

## 没做的

- 没给次级按钮任何液体处理。一屏一个，这是规则不是遗漏。
- 没动 SwimmerUIKit 本体。这里只用它的 `LiquidGroup` 和 `GameButton`。

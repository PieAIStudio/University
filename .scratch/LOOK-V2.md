# 浮空棋盘 — University 程序化地图 v2 美术与架构规格

作者：主控（架构 / 美术总监）。日期 2026-08-30。
这份文件是 v2 的唯一美术依据。它取代 island-look-contract.md 的数值门槛。

## 0. 为什么换

旧路线是"自然写实低多边形"。它失败的原因不是执行不力，是**判据不可检查**：
"这片草看起来对不对"没有程序能算的标准。档案里记了三次"指标过了但画面没好"。

实测对比（2026-08-30，GL 层钩 draw call）：

| | Sky Citadel (参考) | 我们当前 |
|---|---|---|
| draw call/帧 | 18 | 234 |
| 三角形/帧 | 17,539 | 420,668 |
| 导航主线程阻塞 | — | 1,892 ms |

24 倍的三角形，换来更差的画面。

## 1. 核心决定

**格子是数据结构，不是美术风格。**

| 课程模型 | 地图 |
|---|---|
| 一节课 | 一个格子 |
| 一个 unit | 一片连通同色格子（领地） |
| 学习路线 | 一串相邻格子 |
| 进度 | 格子的颜色 / 高度 / 是否揭开 |

选六边形而不是方格：我们的岛是自然主题，方格读作"城建/地牢"，六边形读作
"桌游/自然"。六邻居等距，路线走起来更自然。

**地形自己程序化生成（六棱柱），道具用 Kenney 的模型。**
道具不在乎脚下是六边形还是方格，所以我们拿到 Kenney 329 个模型里最贵的那部分
（树、石、桥、栅栏、蘑菇、作物），而只放弃我们本来就能轻松生成的地砖。

## 2. 不可协商的接缝

`packages/world/src/Maps.tsx:724` 的 `LessonPlacement` **形状不变**：

    { studyId, courseId, unitId, unitTitle, unitIndex, lessonId, lessonTitle,
      chars, position: THREE.Vector3, state, kind, hueShift, blueprint, visualToken }

相机、标签、LabelProbe、点击拾取只消费这个数组。格子系统必须吐出同样的东西，
position = 该课格子顶面中心的世界坐标。**上面那一层一行都不许改。**

## 3. 观感杠杆（这七条决定好不好看，不是"有格子"决定的）

六边形做砸了就是文明的克隆。好看来自：

1. **轮廓永远不是正六边形。** 从路线生长出领地，再用种子噪声侵蚀边缘。
   额外丢 2-4 个分离的小格子/小浮岛在附近。
   这一条是"看起来是设计的"与"看起来是生成的"最大分界线。
2. **3-4 层整数高度，崖面露出来。** 六棱柱的侧面就是崖，法线不同自然变暗，
   明暗免费，不靠打光挣。
3. **岛的底面**：倒锥 + 3-5 根岩刺 + 一道瀑布。"这是飞岛"六成读感来自底面，且很便宜。
4. **路线是实体**：抬高一档的石道格子，独立颜色，串起所有课程格。
   学习路线是构图主角，不是贴图。
5. **云分三层深度**（岛后 / 岛侧 / 岛前）。这是让平涂天空读成天空的东西。
6. **每岛 5 个颜色**：草顶 / 草阴 / 崖 / 路 / 强调。高饱和，明度台阶拉大。
   颜色是**选的**，不是靠光碰出来的。Kenney 模型是无贴图平涂，可整体换色。
7. **当前这节课的格子升起一档并呼吸。** 不用任何 UI，几何本身说"点这里"。

## 4. 格子上放什么（用户明确要求：格子不是光秃的）

三档，按重要性递减：

- **课程格**：顶上放一个 Kenney 道具（按 unit 选种类，同 unit 同款），
  加状态环。这是玩家要点的东西，必须最醒目。
- **领地格**：约每 3 格 1 个装饰（树/石/花/蘑菇），同格绝不放两个。
  密度按到路线的距离衰减——路边干净，远处茂密。
- **空格**：纯色顶面。**留白是设计，不是偷懒。** 参考图里大量格子是空的。

道具全部 instanced，按模型分组。目标每岛 6-10 种道具。

## 5. 预算（硬门槛）

| | 目标 |
|---|---|
| draw call（课程岛相机下） | < 30 |
| 三角形 | < 25,000 |
| 进入课程视图主线程阻塞 | < 100 ms |

先测**关掉 shadowMap** 会怎样。Sky Citadel 18 个 draw call 意味着它几乎肯定没开
阴影贴图。平涂格子的明暗来自法线，未必需要阴影。这是要实测的问题，不是可以假设的结论。

## 6. 程序能检查的判据（这是换架构最大的收获）

前六个模块不 import three，全部可单测：

- 每节课恰好占一个格子
- 路线连通：相邻两节课的格子必须相邻
- 没有两个道具在同一格
- 岛的轮廓是单一连通区域
- 每个 unit 的领地连通
- 格子总数在预算内
- 同一 (course, seed) 两次生成完全一致

**这些是草地永远写不出来的测试。**

## 11. 商业感从哪来（2026-08-30 增补，主控）

**用户的参照是 Clash 那一路的"干净模型 + 商业质感"，不是 Sky Citadel 的纯平涂。**
这两者的差距**几乎不在几何，在打光和收尾**。同一批 Kenney 模型，直接渲出来像
免费素材包，加上下面这套收尾就像花钱做的。

几何负责**正确**，收尾负责**贵**。前面十节全在讲正确，这一节讲贵。

八条，按性价比排序：

1. **每个道具下面一块柔和接触阴影。** 这是"东西是被放置的"还是"东西是浮着的"
   之间最大的一条线。不需要全场 shadow map——一张低分辨率 blob/AO 贴片就够。
   **这一条单独就能把观感抬一档。**
2. **暖冷分光**：暖色主光 + 冷色环境/阴影。这是 Supercell 那类美术读起来"贵"的
   头号技术原因。纯白光 + 灰阴影 = 廉价。
3. **轮廓光（rim light）**：一盏从背侧打的低强度光，把剪影从背景里剥出来。
4. **格子顶面轻微渐变**（顶点色或 ramp），别是纯色贴纸。侧壁比顶面暗一档半，
   不是暗一点点。
5. **缝隙里的环境遮蔽**：道具与格子相接处、格子与格子相接处压暗。可以烘进顶点色，
   零运行时成本。
6. **粗壮化比例**：树干比现实粗，底座比现实宽，蘑菇伞比现实大。
   Clash 的一切都比真实世界胖一圈——这是可爱和可读的来源。
7. **剪影边缘压暗**（轻微 outline 或 fresnel 反向压暗），让每个物体自己成立。
8. **克制的后期**：高光轻微 bloom、温和暗角、饱和度提一点。**要非常克制**，
   过了就是廉价滤镜。

**成本纪律**：这八条加起来的目标是**不超过整帧 20%**。
一盏低分辨率方向光阴影 + 一盏 rim + 一个 grade，不是 24 倍的开销。
如果收尾把 draw call 推过 30，先砍收尾，不砍预算——**正确比贵重要**，
因为不正确的东西再怎么打光也救不回来。

**验收方式**：并排两张图，同一场景，一张只有几何和平涂，一张加满收尾。
差距要一眼可见，否则这一节白写。

## 12. 世界视图的一条修正（2026-08-30，主控看图后）

参考图 `.scratch/artdir/world-view-archipelago-day.png` 证明了**每课一色确实能解决
身份问题**——十几座岛一眼可分，这正是 `work/archipelago-identity` 当年没做到的。

**但那张图的两个做法是错的，不要照抄：**

1. **岛群不能排成整齐的行列。** 那张图把岛摆成了网格，读起来是"标本册/素材表"，
   不是"一片可以飞进去的天空"。位置要散布并且有前后深度差，近大远小。
   我们现在的岛群图在这一点上反而是对的，别退步。

2. **一座岛不能整体一个颜色。** 那张图里粉色的岛从草到崖到底面全是粉的，
   看起来像塑料筹码，不像地方。对比第一张课程岛图：**绿顶 + 褐崖**，
   立刻就读成了土地。

**正确做法：课程身份放在顶面颜色，崖面和底面留在一个共享的土色系里。**

这样 53 座岛既各自可分，又读得出是**同一个世界**里的 53 个地方，
而不是 53 个不相干的玩具。

这一条同样适用于课程岛内部：顶面按 unit 分色，崖面全岛统一。

## 13. 六边形的线露多少（2026-08-30，主控决定）

用户问：结构留着，美术上能不能把六边形的线去掉？

**答案：按功能分三档，不是全留也不是全去。**

理由：表面一旦全部磨平，我们买来的东西就还回去了——
"这节课在哪儿"又需要插一个标记（石墩问题回来）、道具摆放又变回连续散布
（穿模和尺度含糊回来）、岛缘又变成一块要靠审美调的网格（自然主义判断回来）。

| 部位 | 线的强度 | 为什么 |
| --- | --- | --- |
| **路线格 / 课程格** | **最清晰**。抬高一档 + 独立颜色 + 边缘明确 | 这是要点的东西。**形状本身就是可点击的提示**，参考图里最好看的部分正是这些象牙色和珊瑚色的格子 |
| **崖面 / 高度变化处** | **清晰**。侧壁完整露出 | 这是台地的戏剧性来源，也是免费的明暗。磨掉它等于磨掉立体感 |
| **同高度相邻的地面格** | **弱到接近无缝**。顶面合并或只留极轻压暗 | 六块同高的草格之间不需要沟。**去掉这里的线，画面就从"表格"变成"梯田"** |

实现上给一个可调参数 `seamStrength`（0 = 完全无缝，1 = 全露），
默认按上表分档。**这是一个要看着图调一次的东西，不是能在纸上定死的东西。**

净效果：**交互处离散清晰，地面读作土地。** 用户看到的是一片梯田状的浮空岛，
不是一张电子表格；但他要点的每一节课，边界依然明确得没有歧义。

## 14. 三层世界（2026-08-30，主控）

产品有三层 3D，之前的工作只碰了第三层。三层必须是**一套管线的三个缩放级别**，
不是三个各自为政的场景。

| 层 | 是什么 | 一格代表 | 规模 |
| --- | --- | --- | --- |
| **星球页** | 球面 + 标记，选 study | 一个 study | 少数几个 |
| **岛群图** | 一片天空里的岛 | 一门课 = 一簇格子 | 53 门课 |
| **课程岛** | 一座岛 | 一节课 = 一格 | 约 41 格 + 领地 |

### 关键的技术事实

**岛群图和课程岛可以共用同一个 instanced 六棱柱。**
53 座岛 × 约 20 格 = 1,060 个实例 = **一个 draw call 画完整张世界地图**。

这意味着第二层做完第三层之后**几乎是免费的**：同样的纯函数生成，
换一组参数（每岛格子少、相机远、道具只留最大的几个）。

### 星球页的决定：先不定

球面铺六边形是可行的（Goldberg 多面体：六边形 + 12 个五边形），
而且视觉上能让三层说同一种语言。

**但现在定它是过早的。** 视觉语言还没在第三层立住，
在语言存在之前设计最外层，等于用还没确定的词造句。

顺序：**第三层定语言 → 第二层套用（便宜）→ 第三层语言稳了再决定星球页**。
届时的问题是"六边形球体 vs 光滑星球"，判据是第 3 节那条：
**危险的不是风格化，是含糊。** 如果二三层是清晰的格子世界而第一层是光滑大理石，
那就是一处含糊，要么统一，要么让它明确成另一种东西（比如一张地图、一个封面）。

### 岛群图沿用的铁律

第 12 节那条在这里最重要：**课程身份放在顶面颜色，崖面和底面共享土色系。**
53 座岛既要各自可分，又要读得出是同一个世界。

## 15. 岛群图是天空，不是海（2026-08-30，主控）

第 14 节把星球页推迟了，理由是"视觉语言还没在第三层立住"。语言现在立住了，
于是同一条判据反过来指出了一处**已经存在的含糊**，而且它比星球页更紧急。

**岛群图底下是一片水，课程岛底下是天空。** 同一个产品，两套虚构。

判据仍是第 3 节那条：**危险的不是风格化，是含糊。** 产品叫飞岛，
那第二层就不该是海图。这不是审美偏好——一个读者在两层之间来回，
必须始终知道自己在什么里面。

**决定：岛群图改成天空/云海。** 连带两件：

1. **补远景底面。** §3 第 3 条说得很清楚，"这是飞岛"六成读感来自底面。
   岛群图现在每座岛都是薄片。需要 `Underside.tsx` 的远景版本，
   仍然 instanced——53 座岛的底面不许变成 53 个 draw call。
   **在这个距离读不出来的细节（比如瀑布）就不要加，看不见的细节是纯成本。**
2. **大气透视。** 远处的岛被大气冲淡。这比加几何体便宜，
   而且是"这是一片开阔天空"最强的信号。

地平线那条灰米色窄带在改前改后两张图里都读作渲染接缝，一并处理。

### 顺序不变

**第三层定语言 → 第二层套用 → 第二层的虚构对齐 → 再决定星球页。**
星球页的实现已经在跑（Goldberg 六边形球体），但它落地后要回头看一眼：
如果第二层变成天空、第一层是一颗有海的星球，那是同一处含糊换了个位置。

## 16. 星球页第一轮的判定：架构收，画面退回（2026-08-30，主控）

`work/planethex` 第一轮交付：Goldberg 数学正确（240 六边形 + 恰好 12 五边形）、
和平面六边形共用 `InstancedPrismField.tsx`、**36 → 8 draw call，6,164 三角形，
首屏 826ms**。这三条全部保留。

**但它看起来不像星球，像高尔夫球。** 逐条对比改前改后截图后的判定：

| 缺陷 | 违反了哪条 |
| --- | --- |
| 基底浑浊橙棕，study 簇是青/绿/米/正红——不在色表里 | §12：身份放顶面颜色，其余共享土色 |
| 每个 cell 边缘一圈暗缝，整颗球像掉皮 | §13：同高度相邻普通地表近乎无缝 |
| 海/陆/极冰的地形语义整个丢了 | §3：危险的不是风格化，是含糊 |
| 没有边缘光、没有大气 | 一个球体没有边缘光就不像悬在空间里的物体 |

第一条最要命：**这正是 `work/archipelago-identity` 死掉的那个坑**——
用生成的颜色代替色表。那张表和它三个互相拉扯的测试是反复失败换来的资产，
每一轮新工作都必须**用**它，而不是绕过它。

改前那颗光滑星球也不好看，但它读作一颗星球：有海、有陆地色带、有极冰、
有边缘大气光。**六边形版本要把这套语义用格子重建**——不同高度档 + 不同顶面色，
而不是把语义连同光滑几何一起丢掉。

### 一条一般规律

这一轮和岛群图第一轮是同一种失败：**换管线的时候，把"旧实现里正确的语义"
连同"旧实现里错误的技术"一起删掉了。** 技术要换，语义要搬。
换管线的检查清单上应该有一条：**旧的那版，有哪些东西是对的？**

## 17. 液体该做什么（2026-08-30，主控）

第一轮把 waviness 加在静止态上，读作"坏了"。第二轮移到按下。第三轮补材质。
三轮都在问"液体怎么加在按钮上"。**这个问题问错了。**

### 为什么名作里的液体好看

| 例子 | 液体在做什么 |
| --- | --- |
| 灵动岛 | 两个形状**融合**又**分离** |
| Dock / 玻璃 | 表面**折射**它背后的东西 |
| gooey 菜单 | 子按钮从主按钮身上**拉丝分裂**出来 |

**共同点：液体永远在描述"两个东西之间的关系"**——两个形状之间，
或一个形状和它背后的世界之间。**从来不是一个形状自己的属性。**

一个静止的孤立按钮两样都没有。所以把它的轮廓弄不规则不是"更液体"，
是把"没有关系可描述"这件事用锯齿边表达出来。**不规则读作破损。**
规整才是让按下时的形变读得懂的前提——没有可参照的规整，形变就只是噪声。

### 这个产品里，液体唯一该做的事

CTA 的工作是：**「你在这张卡片上」→「你要去那个世界里」**。
屏幕上没有别的元素能表达这件事。

**机制：按下 → 轮廓朝目的地拉长 → 拉丝 → 断开 → 落点变成目的地。**

gooey 在"断开的那一瞬间"是无可替代的，这是它唯一真正不可替代的地方。

| CTA | 目的地 |
| --- | --- |
| 开始学习 | 地图上那节课的格子 |
| 完成本次更新 | 进度条 |

**一套机制，两个目的地。这是系统，不是效果。**

### 可行性不靠猜

按钮是 DOM，地图是 WebGL，不需要真的跨层融合——只需要 DOM 层的一个覆盖元素
从按钮矩形形变到目标的**屏幕坐标**。那个坐标我们已经在算了
（`packages/world/src/labels/path-overlay.ts` 就在做这件事）。

约 400ms，一次导航一次，**静止零成本**。

### 仍然成立的三条

1. **一屏只有一个元素带液体。** 稀缺性是它读作"按这里"而不是装饰的原因。
2. **那个元素上只有一层意图。** 不要按下 + 发光 + 摆动同时来。
3. **静止态的"贵"来自材质与光，不来自动。** 第 11 节对 3D 说的那条同源：
   几何承担"对"，材质光照承担"贵"。

## 18. 星球页：撤销我自己在 §14 的决定（2026-08-30，主控）

§14 把星球页的问题定为"六边形球体 vs 光滑星球"，我选了六边形球体，
理由是消除三层之间的含糊。**两轮之后，我撤销这个决定。**

### 两轮实测

| | 结果 |
| --- | --- |
| 第一轮 | 数学正确、36→8 draw call。但读作**高尔夫球**：颜色不在色表、格子全是裂缝、地形语义丢光 |
| 第二轮 | 地形语义回来了（海 / 陆 / 极冠 / 大气边缘光），但**裂缝更深了**，深红从缝里透出来，读作**裂开的地质标本**；饱和的黄绿和橙并排读作**沙滩球** |

第二轮不是执行不力。**问题是结构性的：**

> 岛群图里格子之间**有空气**——那是岛与岛的间隔，是构图。
> 球面上格子**就是表面本身**——每一条缝都是缺陷，没有一条缝是有意义的。

同一个零件，在一个语境里是构图，在另一个语境里是瑕疵。
再调十轮也不会改变这一点。

### 正确答案在 §14 自己那句话里

§14 原话：**「要么统一，要么让它明确成另一种东西。」**
我当时只读了前半句。

**星球页不需要是一颗球。** 它要回答的问题是"进哪一摊工作"，
而现在只有五个 study。

**决定：第一层就是同一片天空，只是站得更高。**
五片飞岛群，一片 = 一个 study，靠强烈的大气透视拉开距离。

- **语言完全统一**：三层是同一片天空的三个高度，不是三种东西
- **复用已经好看的那个**：第二层是目前全产品最好看的一屏，
  往外缩放到更差的东西是反的
- **更便宜**：不需要 Goldberg 网格，不需要球面着色，
  就是岛群图的相机拉远 + 按 study 分簇

### 一条给自己的规律

Goldberg 那套是对的工程，做完了、有测试、指标漂亮。
**但"它已经做完了"不是保留它的理由。** §14 的判据从头到尾都是画面，
不是成本。两轮画面都不对，就该换问题，不是换参数。

### 顺序

**必须等 `work/prettyisle` 落地再做第一层**——
第一层是第二层拉远，第二层还在变好看，先做第一层等于照着旧的抄。

## 19. 液体断开第一轮：机制对了，落点毁了画面（2026-08-31，主控）

§17 定的机制（按下 → 拉长 → 拉丝 → 断开 → 落到目的地）第一轮实现完成，
352ms + 72ms settle，静止零成本，`prefers-reduced-motion` 正确跳过，
坐标从 `path-overlay.ts` 的投影拿到。**工程侧全部达标。**

**画面不合格，不合并。**

按进度取的帧显示：p070 是一坨压在课文标题上的橙色团块加一颗脱落的圆珠，
读作**泼上去的漆**；p090 收成一根压在标题上的橙色横条，
读作**把标题涂黑的删除线**。

### 根因不是"液体做得不像液体"

是**落点落在了可读文字上**。这个产品最硬的一条规矩是
「可读文字永远是 DOM，不是几何体」，它的精神是**文字不可被遮挡**。
一个盖住本节课标题的效果，比没有效果糟得多。

### 三条新增的硬规矩

1. **效果永远不许遮挡可读文字。** 要么整体在内容层之下，
   要么在接触到文字之前就化掉。这条没有例外。
2. **落点必须是一个认得出的目标，而不是一片空地。**
   如果目的地是标题，就落在它**下方**、化成它的强调线再消失——
   液体**成为**目的地的一部分，不是**压在**它上面。
3. **断开之后的形状是被吸收的小液滴，不是一根横条。**
   横条读作 UI 元件，液滴读作物质。

### 关于跨屏这件事

`开始学习` 的源在首页卡片、落点在课文页，**这是跨屏共享元素转场**，
不是同屏动画。手写一个覆盖层飞到另一页的坐标，本质上是在赌两页的布局。
浏览器已经有 View Transitions 这个原语专门做这件事。

**同屏那一个（`完成本次更新` → 进度条）先做对**，
它的源和落点始终同屏可见，是这套机制唯一今天就成立的场合。
跨屏那个要么用 View Transitions 做，要么先不做——
**一个落点不可靠的转场，好的时候是惊喜，坏的时候是删除线。**

### §19 附记：第二轮通过，两点留给以后

第二轮（`a071327`）达标并合并：

- **红线守住了**：`.scratch/ctapinch/round2/` 全部取样点都没有覆盖任何可读文字，
  而且这一条是用**覆盖层矩形与文字节点矩形相交检测**证的，不是目检——
  第一轮就是目检漏掉的。
- 读作 **鼓包 → 分离 → 飞行 → 化进进度条已填充那一段**，落点成为目的地的一部分。
- `开始学习` 干净关闭，等 View Transitions。

**两点打磨留给以后，不值得现在再开一轮：**

1. **轨迹先向右再折回左上**，而目的地在左上。弧线本身比直线好，
   但先朝背离目的地的方向走一段，读起来像犹豫。
2. **飞行途中液滴太大且是胶囊形**，中段有一帧接近"旁边多了一个按钮"。
   液滴应该边飞边缩——**质量守恒的错觉比形状本身更重要**。

## 20. 参考图那一轮通过，外加一条色表新边界（2026-08-31，主控）

### 主控对代理提出的四个问题的裁决

| 问题 | 裁决 |
| --- | --- |
| 瀑布没有水花和落点石 | **保持现状。** 参考图的瀑布也简单，为它花 draw call 不划算 |
| 台地是"堤道穿过草地"而不是四层大梯田 | **接受。** 路的可读性优先于梯田层数 |
| 岛群图 33 vs 32（`DistantGround`） | **留着。** 那一个 draw call 买的是"我们在多高"，正是产品主人要的那条远处地面；三角形反而更少 |
| `generated-assets` 哈希到 `rust-down`，3 节课的岛读成棕色 | **这是真缺陷，主控亲自修了**，见下 |

### 新增第四条互相拉扯的边界：顶面 vs 崖面

身份放顶面颜色、崖面共享土色——那么**一个和崖面同亮度的顶面就失去了
"土在岩石之上"的那道边**，整座岛读成一坨泥。

实测：`rust-down` 对共享崖面只有 **1.86**，而其余九个全部 ≥ 2.54。
**这是一条整张表在别处都碰巧满足、只有一行漏掉的地板。**

修法不是把它调亮——暖棕那一段已经挤了三个（16°/26°/33°），
调亮只会撞上 `clay-terrace` 和 `autumn-grove`。
色相直方图里唯一的空档在 **75°→122°**，所以它搬到 105° 变成 `spring-rise`
（`0x68bd4c`），对崖面 3.48，最近邻 44。

**攻击测试**：把旧棕色放回去 → 新的崖面对比测试**和**标记可读性测试同时变红 →
撤销 → 321 全绿。**四条边界确实在互相拉扯**，这正是第 6 节要的形状。

### 记下但这一轮不修：色表还有成对邻近问题

按"最大通道差"两两算，当前表最近的几对是：

| 距离 | 一对 |
| --- | --- |
| 15 | `cool-highland` / `mint-shelf` |
| 23 | `dusk-field` / `tundra-flat` |
| 30 | `autumn-grove` / `clay-terrace` |

这两门课基本分不开——**和 `archipelago-identity` 死掉的那个失败同源，只是规模小**。

现有的分离测试量的是**整张表的极差**，不是**两两距离**，所以它看不见这个。
不在这一轮修，是因为画面刚被判定为好，动十个颜色里的四个风险太大；
但**下一次动色表时，先加两两距离这条边界**。

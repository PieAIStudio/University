# Selective hex bevels preserve a seamless meadow

## Guidance

When a low-poly course island mixes semantic route cells with broad same-height meadow, beveling every hex adds 12 triangles per prism but visually creates repeated dark gaps and triangular slivers. A real bevel on route and detached stepping stones, with land seamStrength slightly negative for overlap, kept the route's lit chamfer while preserving the meadow as one terrace in fixed desktop and mobile screenshots. Apply this rule when route edges need physical highlights but same-height land must remain near-seamless; validate both course-design and course-near screenshots before widening the bevel.

## Applies When

- The work is complete and verified.
- The lesson is non-obvious, reusable, and not already documented.

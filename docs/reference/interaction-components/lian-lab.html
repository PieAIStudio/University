涟，换成彩色液体那套新光感会怎样

左边是正式版里现在的「涟」（真实截图）。中间和右边用品牌 UI 包里同样的液体零件重画：形状用「涟」自己的参数（面板边缘鼓包 8、水滴 3.5，各 3 个包），光照你给彩色液体定的新逻辑：「涟」自己的高光（光泽 3.5）收在边缘里面一个像素，边缘不出锯齿；颜色上浅下深，底下一层很淡的影子。

① 现在的涟真实截图

  • 顶上有一圈亮白的反光边，面板有厚度，也更「抢眼」。

② 新光感 · 原来的青色试验

  • 颜色取自现在的涟：顶上青 #27cfd7，往下偏青绿 #22c5b9；「开始」还是橙色。
  • 高光还在，但收在边缘里面，边缘平滑；厚度再加上上浅下深和底下的淡影子。

③ 新光感 · 浅一档的青色试验

  • 和课文页的马卡龙色放在一起最协调；「开始」换成同一套里的珊瑚色。
  • 字一律深色。

这一页只在设计文件夹里。要把这个样子用到正式版的涟，得改 Nerve 包和品牌 UI 包里画涟的那段，发新版本，要你点头。

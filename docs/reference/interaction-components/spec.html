1. 范围与硬约束

硬约束出处对本规格意味着
能读的字是 DOM，不画进 canvasAGENTS.md「Readable text is DOM」；Web3D 基线第 7 条（组合级共享规则）题目、回答、选项、代码、运行记录全部是 DOM。3D 里只允许很短的标签（例如「答得出」），而且也是浮在 canvas 上的 DOM。
一份实现AGENTS.md University 规则 1每种互动组件只有一个引擎、一个渲染；两种模式、三种外壳共用。样机 lab/ 是参考，不许拷进产品。

3. 名词

关一次学习单元（以前叫「节」或「课」）。8–12 屏，8–12 分钟。
互动组件学习者的手在做的动作。课里只有 9 种（B1 时 8 种）。不再叫「手势」「玩法」。
材料动作作用的对象：文字、照片、代码、运行记录、开关、代码小镇。可以加。
舞台屏幕上方的 3D 庭院，一关一个，开场加载。
小回合同一种判断 3–6 道，连在一起做，舞台里有看得见的结果。一关最多一个。
游戏组件岛上计时、计分的游戏。不在课里，不算在互动组件里。题目从学过的关里取。
真实世界料放在一关里的真事、真数字、研究、新闻、真项目代码、网站真在用的写法。每条有出处和复查日期。
带回岛上学完后出现在岛上的一样东西（第一关是一张明信片和一把椅子），加宝箱里的复习卡。

5. 互动组件契约

「现在的引擎」一列是产品里已有的 kind。有两套：第 3 版课的步骤（packages/core/src/domain/schemas.ts，现有 choose、sort、match、build、find、point、send、make）和评估面板用的原生活动（packages/core/src/learning-play/，有 connect、tune 等）。收敛后只能剩一套引擎：步骤版缺的（拧一拧）直接复用原生活动的引擎接进步骤，不另写第二份。每种都有：键盘可达、读屏可读、3D 画不出时的平面样子（本来就是平面按钮，舞台只是陪衬）。

互动组件现在的引擎学习者动作通关条件字段（新增的加 *）舞台反应小兔子吸收了
选一个choose2–4 个里点一个猜：选了就过；自查：选了就过，按选项给下一步；判断题：选对options[id,label,requestId?,after?]；afterreact(ok)主角（走过去）—

6. 材料

// 文字：AI 的回答、说明。实时结果按句切分，点一处的目标用 terms 描述，不写死句子。
{ "kind": "text", "id": "…", "label": "…", "text": "…" }

// 照片：沿用现有 assets（带授权、署名、alt）。
{ "kind": "image", "id": "…", "assetId": "everyday-coffee" }

// 代码：真项目、钉死提交、行号能对上。tokens 是可以点的词。
{ "kind": "code", "id": "share-capacitor",
  "repo": "turing-pact", "commit": "658b36ef0f55",
  "path": "src/platform/capacitor/share.ts", "lines": [4, 11],
  "tokens": [ { "line": 5, "text": "await", "id": "await" }, { "line": 4, "text": "async", "id": "async" } ],
  "highlight": [5] }

// 运行记录：照代码顺序写的回放，必须标「示例」或「录制于 …」，不冒充实时。
{ "kind": "runLog", "id": "…", "label": "示例：照代码顺序写的",
  "variants": { "with": [ { "t": "10:02:03.141", "text": "停在第 5 行，等……", "tone": "wait" } ],
                "without": [ … ] } }

// 开关：改一处，再跑一遍。每个状态对应一份运行记录。
{ "kind": "switch", "id": "await-on", "label": "第 5 行写着 await", "states": { "on": "with", "off": "without" } }

// 代码小镇：模块=房子，数据=小车，路线来自真调用路径。
{ "kind": "town", "id": "storage",
  "houses": [ "业务代码", "存储总台", "手机里的抽屉", "浏览器里的抽屉" ],
  "routes": { "phone": ["业务代码","存储总台","手机里的抽屉"], "web": ["业务代码","存储总台","浏览器里的抽屉"] },
  "code": "storage-switch" }

代码小镇的画法固定：模块=房子；请求/数据=小车；等待=红灯；检查=关卡；存储=仓库/抽屉；出错=冒烟/红旗。真代码永远在舞台旁边（DOM）。

  • 一关最多三条：door、wait、after 各一条。wait 只挂在「跑」那一次发出去上（等 AI 或回放的空当），第二次发出去不挂。
  • 必须 relatesTo 这一关的带走的话。无关的趣闻不放（研究：跑题的有趣内容让学得更差）。
  • 一手出处：公司/机构原文、论文页面、官方文档。转述的二手文章不算。查不到就不放。
  • 公司自己的数字要在 limitation 里写「这是它自己的数字」，正文用「某某说：」开头。
  • 复查日期：数字、新闻 6 个月；研究 12 个月；代码钉提交号，不过期，但项目升级后要重新对行号。到期由写课流程重查，查不到就换掉。
  • 不考它：真实世界料里的人名、年份、机构不做成题（教学合同 F2「案例绑架」）。
  • 数据落点：现有课的 intro.connection 和 sources/evidence 已经有出处结构，扩成 realWorld[]，每条引用一个 source。线上校验同步加。

8. 3D 舞台契约（A1）

  • 一关一个舞台，开场屏加载；之后每屏只 go(step) 转镜头、摆道具，不重新加载。同一门课的几关可以共用一个舞台，换道具。
  • 接口（样机里的形状，产品可改名，语义不变）：go(step)、react("ok"|"no")、各互动组件的动作（throwBall、addWagon、depart、fly、snap、makeItem、celebrate、play、route）。动作都有完成回调，但课的流程不等动画：学习者的点击立即生效，动画只是跟上。
  • 分层：课文阅读器（packages/ui）发出「这一步是什么、学习者刚做了什么、对不对」的事件，并留一个舞台插槽；舞台实现在 packages/world；两者在 apps/university 接上。ui 包保持零 three。
  • 字：舞台里只允许 1–6 个字的标签（「答得出」「AI」），而且是 DOM。题目、回答、代码都在舞台下面。
  • 画不出 3D：没有 WebGL、低端机、用户关了 3D、系统「减少动态」：舞台换成该步的静态图（或只留彩色背景），课照常。减少动态时动画直接跳到结束。
  • 积木：用 packages/world/src/game-kit 庭院拦截那一套（颜色、材质、小兔子），不另起画风。样机 lab/src/kit.js 是照它抄的参考。
  • 小兔子角色：身体的活（走、扔、送）当主角；手指的活（排、接、拧）陪着；眼睛的活（读字、看照片、看代码）不出场或退到边上。
  • 预算（待测，先占位）：舞台首次加载在中端手机 ≤ 待测 秒；稳定帧率 ≥ 待测；额外下载 ≤ 待测 KB。样机整个 3D 包（含 three.js）约 0.9 MB，产品里 three 已经在，增量应远小于此。
  • 闸门：加载看帧时间，不看截图（项目教训）；截图只用来给人看。

9. 带回岛上与游戏组件

  • 每关一个 islandItem：学完出现在岛上（第一关：明信片摆上小屋的架子，庭院多一把椅子）。接 V7 的宝箱与徽章，不另起一套奖励。
  • 宝箱里是这一关的复习卡（沿用现有 cards）。
  • 「今天就用一次」（J1）：学完页一句具体的生活任务；下次打开问「用了吗？」，用了给岛上贴纸。只算贴纸，不算成绩，因为无法验证。
  • 游戏组件（I1）：连连看（题目来自学过关的「连一连」）、贪吃蛇（来自「排一排」）。计时、计分；分数不进成绩；用同一套积木。庭院拦截不变。

16. 这些样机怎么改

  • 三个页面都是纯静态文件，双击打开，不联网。3D 是一个经典脚本 lab/toy3d.js（window.Toy = { mount, SCENES, TOY }）；不用 ES 模块，是因为 file:// 下浏览器不让加载模块。
  • 源码：lab/src/kit.js（积木、渲染、DOM 标签、按钮替身）、lab/src/scenes.js（全部场景，含 world-lesson1、world-await、world-town）、lab/src/media.js（咖啡照片内联成 data URI，因为 file:// 下图片不能当 WebGL 贴图）。
  • 改完源码重新打包：
    node docs/reference/interaction-components/lab/src/build.mjs
    它用仓库里已装的 rolldown 和 packages/world 的 three（0.185.1），输出 lab/toy3d.js。
  • 两个课样机共用 lab/lesson.css 和 lab/lesson.js（DOM 小工具、出处折叠、步骤机）。课文在各自页面的脚本里。
  • 无头浏览器里测 3D：Chromium 加 --use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist；软件渲染很慢，动画时间要放宽。
  • 总览页 index.html 按 design-before-build 技能的讲解旅程格式写，改完用它的 check_walkthrough.py --allow "University,组件" 检查。
  • 本文件夹只有 HTML 和图片，不进文档治理的 MANIFEST（和 player-journey v7 的做法一样）。

18. 风险与未决

  • 手机性能没测。一关一个舞台在中端安卓上是否流畅，是 A1 成立的前提。测不过就启用「换个思路四」（课里只留会动的平面小兔子）。
  • 实时回答不可控。点一句 / 连一连依赖 AI 实时结果，课文只能用条件句；要有「它没提到」的出口（样机第 4 屏已示范）。
  • 真实世界料会过期。复查日期要有人（或流程）真去查，否则规矩只是写着。
  • 删课的连锁反应。§10 的五条没做完不许删。
  • 英文版。新第一关只有中文样机；英文课文、英文真实世界料要在第 5 步一起做，不能等上线前再补。
  • 和 V7 的衔接。「带回岛上」接 V7 宝箱与徽章；V7 app 侧的接线还在进行，先对齐再做。
  • 设计入账。批准后写进 player-journey 的下一版（或 v7 修订）；本文件夹保留为设计稿。

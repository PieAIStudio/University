这一页负责：信息层级、区块顺序、证据锚点长什么样、代码块在窄屏怎么办、答题框在哪、状态。 不负责：最终配色、字体选型、动效。颜色来自 kit，不在这里定。

发现：kit 的字号表不是读长文的字号表

  • SwimmerUIKit 的正文档位是 0.82 / 0.95 / 1.18rem。那是按钮和 HUD 的尺度。
  • 本节课 2606 字，全库均值 2363、最长 4903，还带 968 段代码。0.95rem 读它是折磨。
  • 结论：阅读字号与行高属于 @pieai/university-kit，不属于游戏 UI kit，也不该在产品里散着写。这一页把它标出来，作为抽包时的第一条依据。

为什么答题框是真的输入框

  • 中文输入法、可选中复制的代码、无障碍、手机键盘，在 WebGL 画布里全部退化。
  • 这是已登记的 Web3D 基线规则 7，不是偏好。
  • 所以战斗 HUD 可以叠在 3D 上，输入框永远是 DOM。

分级问卷与面板 · 线框

2D · 第 3、26 幕 · 题面来自上游真实的三道题 · 需要 pnpm dev 打开

验收

面板上必须同时出现「你当初说 X」和「我们看到的是 Y」两行， 并且改起点的按钮写的是手动覆盖的意思，不是「重新测一次」。

这一页负责：作用范围、答案存在哪、面板显示什么、覆盖按钮说什么、旋钮能动什么。 不负责：题目本身好不好（那是内容）、模型分级、最终配色。

作用于「一整条系列课」，不是一门课

  • 上游那个雏形写死在 React 组件里，只对 foundations-before-zero 一门有效，导出包完全看不见它。
  • 正确的作用范围是 foundations 那条九门课、139 节的完整主干——学习者是在为整条路选起点，不是为一门课。
  • 所以数据要分三处放：题面与入口点属于课程包，打分规则属于共享包，学习者的答案属于 SwimmerBackend。没有一样属于 React 组件。见待决 D7。

为什么按钮不能叫「重新测一次」

  • 问卷是冷启动的猜测。一旦有了真实答题记录，真实记录永远优先。
  • 说「重新测一次」等于承认问卷还是权威，于是产品里就有了两个互相打架的真相源。
  • 打个比方：入学填表说自己是初学者，一学期次次满分——这时候该改的不是那张表，是你对他的判断。表只是当初没有别的信息时的替代品。

旋钮只能动三样

  • 起点、跳过粒度、复习强度。动不了题目难度——题目是从 UniversityLocal 导入的固定内容，产品这边变不出更难的题。
  • 而且复习强度要小心：FSRS 已经是卡片级的难度调节器。再加一个课程级的，两者会打架。所以课程级只调 FSRS 的目标保持率，不自己改间隔。
  • 推荐起点，但不锁其他课。

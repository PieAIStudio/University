导师对话与付费墙 · 线框

2D · 第 20–22 幕 · 成本第 3 层唯一的出口 · 需要 pnpm dev 打开

验收

切到「额度耗尽」，屏幕必须证明只有辅导按钮变灰—— 读课文、确定性判分、复习、申诉全部照常，学习者仍能完整走完一节课。

这一页负责：入口有几个、额度怎么显示、付费页什么时候出现在哪、额度耗尽后还剩什么能用。 不负责：提示词、模型选型、对话质量、最终配色。

入口只有两个，这是成本设计不是产品洁癖

  • 答错两次；或者主动点「我不懂」。没有第三个入口。
  • 一个 AI 学习产品最常见的死法是用得越多亏得越多。入口越窄，第 3 层的调用量越可预测。
  • 对照第 1、2 层：确定性判分零边际成本、小模型极低。只有这一屏花钱，所以只有这一屏设闸门。

付费页为什么在「讲通之后」

  • 他买的不是「课程」，是「卡住时有人讲给我听」。所以要先让他体验一次那个价值。
  • 形态是接在解释下面的一块，不是弹窗。弹在正在读的解释上面，等于把刚卖出去的东西砸了。
  • 验收：付费块出现时，上面那段解释仍然完整可读、可滚动、可复制。

额度耗尽不是把产品锁上

  • 变灰的只有「讲给我听」。
  • 读课文、做确定性题、复习到期卡、发起申诉——全部照常。
  • 申诉尤其重要：误判是分层判分自己的故障，不该由学习者的额度买单。

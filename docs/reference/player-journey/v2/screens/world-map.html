世界地图 · 灰模

L1 · 用 52 门真课渲染 · 全灰 + 一种强调色 · 需要 pnpm dev 打开，不能双击

验收

不看教程，8 秒内指出「我下一节课在哪」，并说出它属于哪个产品。

灰模只回答四件事 构图、层级、镜头、可达性。材质、灯光、颜色、模型精度不在这一页里定。
这一页负责：世界怎么分、岛怎么排、路怎么连、镜头怎么飞、找不找得到下一节课。 不负责：颜色、材质、天空、地形细节、小人长什么样、动效曲线。

为什么是这个形状

  • 一个 study = 一个真实产品 = 一条向上爬的路，不是一块平铺大陆。
  • 深度 → 距离 + 高度。turing-pact 那条链有 14 层，平铺会变成看不到头的走廊；抬高之后，起点就能看见山顶。
  • 岛的半径按课时数开平方。41 节和 1 节都真实存在，线性缩放会让最大的岛是最小的 40 倍。
  • buzz 五门课没有先后关系，就画成没有路的一圈。假造顺序比承认平铺更糟。

坐标从哪来

  • 种子是 studyId / courseId，不是包哈希。作者改一个错别字，世界不该重排。
  • 没有关卡编辑器，没有坐标表。地图是课程结构的函数，所以这里不存在第二份课程结构。
  • 文字全部是 DOM 叠加层，投影定位。画布里没有一个字——这正是产品规则第 7 条。

状态

  • 空：一门课都没导入 → 不进地图，进空态页。
  • 加载：拓扑先到、几何后到，先画 2D 列表再淡入 3D。
  • 错误 / 弱 GPU：直接 2D 降级视图，结构完全一致（上面那个开关就是它）。
  • 离线：已导入的世界照常可见。

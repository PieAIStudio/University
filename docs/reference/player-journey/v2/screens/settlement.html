验收

屏幕上必须出现「明天 N 张」这个具体数字，而且它要比连击数字更显眼。 没有它，连击只是一个数字。

这一页负责：什么最显眼、掉落的是什么、注册请求的位置与措辞、跳过之后会怎样。 不负责：掉落动画、音效、连击的视觉设计、最终配色。

掉落的是卡片，不是金币

  • 金币是产品发明出来的，谁都能发；卡片是这节课的记忆，只有真的学过才会有。
  • 卡片直接进 FSRS 队列——这是「明天会回来」的物理原因，不是心理暗示。
  • 全库 1236 张卡片全部是 basic（正/反两面），没有 cloze，所以这一屏只画一种卡型。画不存在的卡型等于给实现下错误的订单。

注册为什么排在最后

  • 按实测，走到这一屏他已经花了约 11 分钟（V1 以为是 5 分钟）。
  • 所以措辞是「保存你刚拿到的东西」，不是「创建账号」——他手里第一次有值得保护的东西。
  • 可跳过。跳过后成果留在本机，下次仍在。把注册做成闸门，会把整段旅程最贵的一次流失放在最不该放的位置。

状态

  • 第一次：出现注册请求。之后再结算不再出现。
  • 加载：先出结算标题与骨架。
  • 读不到卡片：给生成命令，不伪造卡片。
  • 离线：卡片本地入库，同步排队，屏幕不提这件事——学习者不需要知道。

为什么需要一次性全量数据展现

  • 2D 降级导航的最大挑战在于承受整体的认知负荷：52 门课、146 单元、560 节。
  • 这是它相对灰模的价值：灰模可以只画一个 study，列表不行。
  • 键盘可完整操作（这是它存在的第二个理由：无障碍）。

先修链与状态推导

  • 进度状态（已完成、可进入、未解锁）不直接存储，而是基于课程所在 depth 及其先修依赖实时演算出。
  • turing-pact 的 14 层先修链，通过排序 depth 并结合层级标识（L1-L14），变得直观可读。

诚实的平铺

  • 对于像 buzz 这样有多门课程没有任何先修限制的 study，我们必须如实将它们平铺展现。
  • 为了好看而隐藏层级或发明顺序，就违背了「和 3D 地图结构完全一致」的基线承诺。

# 作废：自然岛屿参考图（v1）

**不要拿这三张图当参考。** 它们画的是六边形改版之前的自然岩崖飞岛，
和现在渲染的东西是两种做法。

2026-08-31，我在讨论飞岛底面为什么糊成一团暗块时引用了这组图，被菲哥
当场纠正：参考图本身就是错的版本。一组作废的参考图留在
`docs/reference/` 下，下一个 AI 还会照着它做——所以它挪到这里，而不是
删掉：删掉就不知道当初为什么会错。

**当前有效的参考图：** `docs/reference/island-art-reference-v2/`

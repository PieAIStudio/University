# Commercial Model

这页说明目前卖什么、哪些能力只是配置、收钱前还缺哪些证据。具体价格与权益
以代码为准，完成状态以现有交付计划和实际服务验收为准，不再把旧成本估算或
营销假设写成当前产品已经做到的事实。

本轮 Owner 授权完成真实来源双系列、产品改进与网站发布，**没有授权启用真实扣款**。
两条小白路线与现有课程的发布不等于商品收费已经开放。

## 当前事实在哪里

| 要确认的问题 | 权威来源 | 不可混淆的边界 |
| --- | --- | --- |
| 免费与会员分别包含什么、月付年付多少钱 | [plans.ts](../../../packages/core/src/billing/plans.ts) 与 [ADR-0007](../../adr/ADR-0007-published-course-packages-are-separate-from-entitlement.md) | 价格配置不是服务端报价、商户批准或已开通销售 |
| 课程是否已经进入交付目录 | [published-catalog.json](../../../apps/university/published-catalog.json) 与正式构建生成的 content/manifest.json | 本地存在课程不证明官网已更新；以实际官网 release.json 及内容校验为准 |
| 浏览器能否真正下单 | [后端支付适配器](../../../packages/backend/src/payment.ts) 与 [支付缺口](payment-backend-gap.md) | 当前适配器只有余额、权益读取；没有下单、订单查询和订阅管理接线 |
| 购买过程中如何处理账号、报价和恢复 | [PaymentPort](../../../packages/core/src/ports/payment.ts) 与 [会员页](../../../packages/ui/src/navigation/screens/PlansScreen.tsx) | 前端保护与测试通过不等于真实结算、取消和退款通过 |
| 这次内容与产品发布做到哪一步 | [双系列交付计划](../../plans/active/00-ai-literacy-commercial-release.md) | 只在该计划维护任务状态，不在这里再造一份完成清单 |

当前配置仍允许阅读全部已发布课程，收费方案授予 AI 与同步相关权益，不是给
两套新课单独设付费墙。免费方案的同步配置为不包含，会员配置包含同步；实际
账号绑定、权限执行、离线缓存与跨设备结果仍须分别验收。旧文写的“免费同步
已包含、只差设备数量”不再作为当前依据。

开放辅导的配置旗标也不是已经交付的服务。会员超过免费批改额度不表示无限
调用，钱包计费与必要限制仍须讲清。页面不能承诺不存在的辅导，不能让用户把
内部记账单位当另一种货币来心算。英文和中文应表达相同权益与费用边界。

## 收费前需要确定的商品

Owner 选择先把两条小白路线做成能学习、能产生真实成果的精品，不先建设全部
学科。这个方向已经进入上述计划；**精品课程的完成不是收费模式自动改变的授权**。

若后续决定销售课程包或包含固定服务期的学习服务，需要先在现有用户旅程与
权益合同中说明：免费体验到哪里，付费买到什么，使用多久，必要的练习反馈是否
包含，额外调用怎么计价，取消与退款怎样处理。不能仅改购买文案而保持权限
模型不变，也不能偷偷收回原本承诺免费开放的课程。

旧文记录的 Paddle 优先方案及其理由保留在历史记录；本轮没有改变渠道选择，
也没有确认该服务商已经接受 Owner 的经营主体。主体资料、收款账户、服务商
准入、实际服务条款和启用销售仍由 Owner 确认。支付工程不在 University 复制
第二套订单、验签、钱包或身份服务，通用能力继续由品牌 Kit 和共享 Backend 承担。

## 成本怎样算，才不会产生虚假的利润

旧稿引用的独立 grading 应用路径和模型费率不能直接用于现行成本承诺。重新
计算时，从实际部署的共享 AI 路由、调用用量、账单和售卖服务期取数。写课时
本机模型的费用与顾客使用产品时的费用分开计算。

一笔销售留下的钱，应扣除支付及渠道费用、实际退款、AI 调用、可归属的交付
资源和人工支持；再扣获客成本，剩余部分才用于覆盖固定经营支出。税费按实际
合同与所在地要求核对，不在本页猜测适用规则。没有这些输入，不能把“模型
单次很便宜”写成“整个产品已经高利润”。

预算与滥用保护也要看实际服务端约束。只限制一个匿名账号，不证明清除浏览器
或新建账号后仍有总量控制；登录、限额和服务端预算都要有各自的真实证据。

## 经营数据与推广

[现有统计适配器](../../../apps/university/src/analytics/productAnalytics.ts)记录
学习与购买意图。`purchase_requested` 表示请求购买，**不是成交、到账或收入**。
最终收入、退款与取消事实必须来自可信的服务端订单和支付服务，不从按钮点击
或成功页反推。统计身份与隐私保护也不等于已完成所有市场的法律审核。

推广优先使用真实课程里的小发现与互动成果，链接到实际可用的试学入口。课程
数、可索引地址、语言支持及官网版本都以当前发布产物核对，不复用旧的固定数字。
不把一次机器检查或模型自评称为真人学会，也不把 Owner 能读懂等同于海外市场
已经验证。真实用户的完成、退出、求助和退款，才是后续改进商品的依据。

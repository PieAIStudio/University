## 方法依据

- W3C Button Pattern（2026-09-18读取）：Space/Enter在原生按钮上保持激活语义。
- Floating UI FloatingFocusManager（同日读取）：默认模态会锁住焦点；地图选中不是模态。
- W3C Character Key Shortcuts（同日读取）：本轮快捷键限定地图焦点，保留可见导航内替代入口。

这些依据不代替产品实测或全站无障碍合规审核。原九张批注截图仍无本地原件，
当前页面重拍和本轮新测试须明确区别于原始证据。实际收据留在
`.scratch/map-navigation-evolution/`，最终结论见本页开头。

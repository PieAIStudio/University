# Reversible wax study

`/play-lab/wax-island` uses the existing eight-node browser-AI course, CourseScene,
AvatarKit and Stage. Classic/wax, camera bookmarks, normal softening, scattering
and no-grade diagnostics do not write course progress or account preferences.

`wax-surface.ts` is the one-consumer experimental finish: preserved pigment/maps,
matte lobes, low-frequency pigment and per-light approximate internal spreading.
Role depth is authored, not a measured thickness map. Normal copies change no
positions, indices or UVs. Classic restores exact source material/geometry IDs.
`wax-owner.ts` owns only this slice subtree and its copies, including late models,
array slot replacements and cleanup; borrowed kit/GLTF resources stay borrowed.

This is not a second global appearance system. If integrated with the clay lane,
its common owner must select one finish and skip/replace this local owner. Accepted
shared response belongs in RenderKit; no kit source has been copied or published.
The comparison freezes this branch's scenery revision, not the parallel clay
branch's later scene. The nine approved games stay unchanged.

The active 3D plan owns status and evidence. Tests cover exact restoration,
shader failure, no source disposal, browser/resource cycling, actual navigation,
mobile input and WebGL loss. Phone viewports are emulated, not device benchmarks.

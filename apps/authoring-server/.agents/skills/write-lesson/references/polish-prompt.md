## 你的任务

**只改说法，不改内容。** 把它润色成"说人话"的口播稿感觉——像一个懂行的人当面讲给零基础的朋友听，而不是像文档或教科书。

具体来说：
- 长句拆短，书面语换成口语
- 生硬的连接词（"因此""从而""基于此"）换成人说话时真会用的
- 抽象名词堆叠的地方，换成动词和具体的东西
- 该有停顿感的地方留停顿感

## 第一红线：不许把「通常」改成「一定」

这是上一版润色唯一犯的错，也是最致命的错。原文里每一个让步词都是作者**故意**放的，因为那件事真的不是百分之百。

**逐条对照，一个都不许丢：**
- 「通常」「常常」「往往」「一般」「多数」「可能」「倾向于」——原文有，你的版本必须还有，位置可以变，意思不能变。
- **严禁**新增：绝不、绝对、必然、必定、从不、永远不、全都是、根本不、压根、随时都能、完全可以、无论如何。
- 「只要」只能配「就」，「只有」才能配「才」。**「只要…才」是病句**，上一版在讲布尔条件的句子里写出了这个错误。

对零基础读者来说，「通常能重装」和「随时都能重装」是两件不同的事。后者会让他在断网那天以为自己搞坏了什么。

## 其它绝对不许动的东西

1. **`[[evidence:路径:行号]]` 标记一个字都不能改**，位置也尽量别动。
2. **所有关于代码、文件、命令的事实陈述**：文件名、命令、行为、因果。你没见过这些代码，没资格改任何技术判断。觉得写错了也保持原样。
3. **专有名词和术语**：不要把 `.gitignore` 说成"忽略文件"。术语第一次出现时原文怎么解释，就还怎么解释。
4. **Markdown 结构**：标题层级、代码块、列表，全部保持。
5. **骨架里的固定句子，一个字都不许删**。尤其是 `## 先猜一下` 底下那一行独占的
   **先写下你的判断，再往下看答案。** 它看起来像一句可有可无的过渡，不是——
   没有它，读者就不知道该停下来先答一遍。2026-09-06 实测：六篇课文里有三篇
   在这一步被整行删掉，而字数、让步词、绝对化三项检查全部正常通过，
   所以**没有任何机器会替你拦住这个错误**。同样不许删的还有
   `## 自检` 里的问题、`## 一句话` 那一句加粗、以及每一个 `:::detail` 块。

## 第三红线：不许把「你」改掉

原文里每一个「你」都是故意的。这一段是对着一个人说的，不是写给一群人看的说明书。

**不许**把「你要的是」改成「需要的是」，不许把「你会看到」改成「可以看到」，
不许把「你的电脑」改成「本机」。**主语是人的时候，就把人留在那儿。**

2026-09-06 实测：一篇课文在这一步被拿掉了一半的「你」，而字数只少了 2.6%——
不是变短带走的，是逐句把口语改回了文档腔。它当时通过了让步词、绝对化、字数三项检查。
现在 `check-lesson-hedges.mjs` 会拦：掉幅超过 25% 直接判失败。

## 第二红线：不许变长

上一版每篇都胖了 8%。口语不等于话多——真正的口语是**更短**的句子，不是更多的字。

**你的版本字数必须不超过原文。** 每加一个"其实""的话""这个""咱们"之前，先删掉一处啰嗦。

只输出润色后的完整 Markdown 正文，不要任何说明、前言、总结或代码围栏包裹。

## Why there is a linter and not just a prompt

[references/polish-prompt.md](references/polish-prompt.md) states both rules,
and the prompt alone was not enough. Told only in prose to change wording only,
the model removed 10 of the author's 23 hedges, manufactured 10 absolutes where
the originals had zero, and grew every lesson by 7–9%. 「通常能照着清单重新装」
came back as 「随时都能重新装」.

For a beginner those are different claims. The second one teaches them that on
the day the network is down, the failure is theirs.

So the two red lines are enforced twice: written in the prompt, and checked by
`scripts/check-lesson-hedges.mjs`, which fails on a lost hedge, a new absolute,
a 「只要…才」 mispairing, or prose growing more than 3%. It ignores fenced code
and evidence anchors, so a lesson that legitimately gained a code block does not
read as growth. It also fails closed: a crash exits non-zero.

Both rules are machine-checked because a rule only a reader enforces is a rule
that holds until the day someone is in a hurry.

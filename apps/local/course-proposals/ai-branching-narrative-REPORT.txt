Most counter-intuitive finding (also in the course)
---------------------------------------------------
rejoinSceneId is required in the model JSON schema and the system prompt
orders the model to return it unchanged — but generateAiBranchWithMastra
captures body.config.rejoinSceneId once, and the response always uses that
captured value. The parsed model field is discarded. Prompt + schema make
the model *perform* compliance; the assignment is the real enforcement.
The same pattern appears for speaker/art/portrait via pickFromPool (invalid
keys silently fall back to pool[0]) while endings throw on forbidden speakers —
branch is soft-downgrade, ending is hard-fail, because product stakes differ.
